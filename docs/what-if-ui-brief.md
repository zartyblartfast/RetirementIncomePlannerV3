# What If comparison — focused journey

Desktop-first retirement planner, with a responsive narrow layout. A novice should change one income assumption and see whether it helps; an expert can still inspect annual results, historical stress and saved scenarios.

1. Start on the Dashboard and choose **Explore a change**.
2. Edit the sandbox income target; see Current Plan and provisional sandbox results together, using each plan's selected end age.
3. Discard changes to return to the Current Plan, save a scenario for later, or confirm a scoped update to the Current Plan.

The comparison reports the planning income reference, first modelled shortfall and capital at plan end. This is a modelled projection, not a guarantee. For portfolio-driven strategies the income reference is a planning benchmark, not a withdrawal target. Preserve existing projection, tax, stress, saved-scenario and annual-workings paths; do not introduce external storage.

The scoped update copies strategy/income target/CPI, drawdown order and pension-access events, but **not** retirement/end ages, balances, guaranteed-income sources or tax settings. A retirement-date-only change can be explored and saved, but cannot be applied by that action. The button must not suggest an update where nothing in its scope would change.

Keep the existing palette and controls; position the direct comparison ahead of the detailed charts. Verify target change, discard, confirmation/cancellation, fixed-target and portfolio-driven language, narrow-width layout and Current Plan persistence in the actual browser.
